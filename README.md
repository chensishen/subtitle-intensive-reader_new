# Subtitle Intensive Reader

一个用于字幕精读的本地 Web 应用。导入音视频和 SRT/VTT 字幕后，可以在播放、跳转、循环跟读和不同布局之间切换，适合语言学习、听写和字幕精读。

## 功能

- 导入本地音频或视频文件
- 导入 `.srt` / `.vtt` 字幕文件
- 字幕列表点击跳转播放位置
- 阅读模式与精读循环模式
- 主视图与文本视图两种布局
- 支持拖拽调整主视图媒体区域宽度
- 文本视图下支持拖动迷你视频窗口
- 支持字幕与翻译分别模糊，便于先听写或先理解再核对
- 播放、暂停、上一句、下一句等键盘快捷操作

## 字幕与翻译模糊

底部控制栏提供“模糊 / 字幕 / 翻译”两个开关。

- “字幕”默认对应每条字幕的第一行
- “翻译”默认对应每条字幕的第二行及之后内容
- 如果字幕只有单行，开启“字幕”模糊会隐藏这一行
- 鼠标悬停到模糊文本上可以临时查看原文
